TK intro.

- Records in a space are ordinary atproto records, defined by Lexicons, read and written with the same helpers as [public data](/guides/reading-data).
- Differences are in where they live and who can read them. See [Differences from public data](#differences-from-public-data).
- Uses `@atproto/lex-space`, alongside the `@atproto/lex` client from [Reads and Writes](/guides/reads-and-writes). TK: Go.

## Space types

TK

- A space type is a Lexicon with `type: "space"`, listing the record collections it's meant to hold.
- `key` controls the space key: `literal:self` means one space of this type per account, like a profile record.
- Install and build it like any other Lexicon ([Developing with Lexicons](/guides/installing-lexicons)).

## Permissions

TK

- Apps get access to spaces with `space:` OAuth scopes, by space type and authority. See [Permission Requests](/guides/permission-requests).
- Default is the user's own spaces (`authority=self`); `authority=*` covers spaces where the user is a member.
- Creating a space needs `manage=create`.
- `read` reads every repo in a space; `read_self` only the user's own.
- TK verify: a bare `space:<nsid>` scope resolves the published space-type Lexicon to fill in collections, so publish it first.

## Differences from public data

TK

- **Per-space repos.** Each member has a separate repo for each space, on their own PDS. Not part of their public repo.
- **No firehose.** Space records aren't broadcast or carried by relays. See [Space sync](/guides/space-sync).
- **Addressing.** Space record URIs include the space. XRPC calls take `space` as well as `repo` (`com.atproto.space.*`, not `com.atproto.repo.*`).
- **Create the space first.** Writing to a space that doesn't exist fails with `SpaceNotFound`.
- **Errors.** `SpaceNotFound` doesn't tell you whether a space doesn't exist or you can't access it. Also `SpaceDeleted`, `AppNotAuthorized`.
- **Blobs.** Uploaded the usual way, then referenced from a space record. TK: reading space blobs.
- **Access control, not encryption.** Anyone with access to a space, including apps, can read it.
- **Same:** Lexicons, rkeys, validation, `create`/`put`/`delete`/`get`/`list`.
